SOLYN — repositorio del sitio (GitHub Pages)

Web publicada en https://infosolyn-afk.github.io

Estructura:
  index.html         Página principal (ES/EN automático)
  privacidad.html    Política de privacidad
  sphere.js          Sol 3D del hero
  assets/            Logos, íconos, PDFs del Playbook (ES/EN), fotos de testimonios
  fonts/             Tipografías (Bebas Neue, Syne, DM Mono)
  vendor/            Librerías (Three, GSAP, ScrollTrigger, SplitType, Lenis)
  video/             Video explicativo (ES/EN) + posters
  v2/                Redirección a la raíz (el sitio vivió ahí durante el desarrollo)
  LEADS-SETUP.md     A dónde llegan los leads (Google Sheet + email) y cómo cambiarlo
  leads-apps-script.gs  Código del script de Google que guarda los leads

El sitio es estático: no requiere build, Node ni base de datos. GitHub Pages publica
automáticamente cada cambio en la rama main (tarda 1 a 2 minutos).
La web anterior (v1) quedó en el historial de git (commits previos al 3/11/2026).
