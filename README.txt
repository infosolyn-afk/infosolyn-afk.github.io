SOLYN — repositorio del sitio (GitHub Pages)

Dos webs conviven en este repositorio:

  /            Web actual (v1): index.html + assets/ fonts/ src/ vendor/
               Publicada en https://infosolyn-afk.github.io

  /v2/         Web nueva (v2), con la lógica de conversión: v2/index.html + v2/assets/ ...
               Publicada en https://infosolyn-afk.github.io/v2/

Ambas son estáticas: no requieren build, Node ni base de datos. GitHub Pages publica
automáticamente cada cambio en la rama main (tarda 1 a 2 minutos).

Para reemplazar la v1 por la v2 cuando esté lista: mover el contenido de v2/ a la raíz.
